# Assets

## Screenshot

To add a screenshot:

1. Run `brew-tui`
2. Take a screenshot showing:
   - Package list with search active
   - Status icons (Current, Outdated, Pinned)
   - Details panel or dependency tree visible
3. Save as `screenshot.png` in this directory
4. Uncomment the screenshot line in the main README.md

## Recommended Screenshot Settings

- Terminal: iTerm2 or similar with good color rendering
- Window size: 160x40+ characters
- Font: A popular monospace font (Fira Code, JetBrains Mono)
- Show a few interesting packages (git, node, rust, etc.)
- Include at least one outdated package
- Make sure status symbols are visible (✓, ↑, 📌)

## Optional Assets

- `demo.gif` - Animated demo of filtering and navigation
- `icon.png` - Project icon (if created)
